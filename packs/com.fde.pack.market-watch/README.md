# 交易盯盘与复盘

**适用对象**：做期货 / 股票的个人交易者，尤其是一个人盯多个品种的人。

## 套用后会得到什么

1. **一个项目桌面**：自动打开行情页、交易所公告，装了文华财经 wh6 会自动打开（两种常见安装路径都试了，都没有就跳过）。
2. **五条上下文材料**：风控铁律、品种参数、开仓前置条件、复盘四问、交易所公告入口。
3. **一条工作流**：盘前计划 → 看公告 → 收盘复盘 → 生成复盘上下文。
4. **一个可运行脚本**：`交易复盘`，接上交易记录 CSV 就算出胜率、盈亏比、计划外交易数。

## 参数说明

| 参数 | 作用 |
|---|---|
| 主要品种 | 决定项目名；多品种可以各建一个项目，切走即隐藏 |
| 单笔风险上限 | 写进风控铁律，改一次全项目生效 |
| 交易时段 | 日盘 / 夜盘 / 全时段，写进品种参数 |

## 这个包真正解决的问题

交易软件最烦的是**切走后还在任务栏晃、弹预警条盖住别的软件**。FDE 的窗口归属会把 wh6 的主窗口、下单窗、预警条都归到「盯盘」这个桌面，切到别的项目就全部收起 —— 你在做别的事时不会被行情打断，切回来它们又都在原位。

## 接入交易记录

项目设置 → 功能/脚本 → 给「交易复盘」加参数：

```
-DataFile "D:\交易\记录.csv"
```

CSV 需要七列：`合约,方向,开仓价,平仓价,手数,盈亏,是否计划内`。最后一列填 `是/否`。

## 建议的改造方向

- 每个品种一个项目，切品种就是切桌面，比在一个界面里切标签页清晰
- 盘前计划的 node 文字直接改成你自己的固定问句
- 把「复盘四问」导出给 AI 节点，每天自动生成一段复盘文字
