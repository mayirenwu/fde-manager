# 外贸询盘跟进

**适用对象**：外贸业务员、中小出口企业的销售岗。

## 套用后会得到什么

1. **一个项目桌面**：自动打开阿里国际站、WhatsApp Web、领英、企业邮箱。做欧洲客户和做中东客户可以各建一个项目，互不干扰。
2. **五条上下文材料**：产品与外销口径、报价公式、跟进节奏、客户分级标准、HS Code 查询入口。
3. **一条工作流**：询盘 → 分级 → 背调 → 汇总 → 写开发信。
4. **一个可运行脚本**：`今日询盘汇总`，接上台账 CSV 就能算出超时未回的询盘和 A 级名单。

## 参数说明

| 参数 | 作用 |
|---|---|
| 产品线 | 决定项目名，也写进上下文里的产品口径 |
| 主要市场 | 欧洲 / 北美 / 中东 / 东南亚，影响报价与跟进话术 |
| MOQ | 写进上下文，报价时不用反复查 |

## 接入询盘台账

项目设置 → 功能/脚本 → 给「今日询盘汇总」加参数：

```
-DataFile "D:\外贸\询盘台账.csv" -OverdueHours 4
```

CSV 需要四列：`客户,等级,收到时间,状态`。状态用 `新询盘/待回复/已报价/已成交/已关闭`。

## 最有价值的一点

「跟进节奏」那条上下文，是这类生意里最容易漏的东西。把它放在画布上每天过一遍，比记在脑子里靠谱——外贸丢单多数不是价格问题，是回慢了。

## 建议的改造方向

- 按市场拆成多个项目（欧洲项目、中东项目），每个项目一套上下文
- 加一个「样品发出跟踪」节点，挂在报价之后
- 把常用的开发信模板放进上下文，让 AI 节点直接引用
