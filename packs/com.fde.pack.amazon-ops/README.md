# 亚马逊店铺运营

**适用对象**：一个人或小团队运营亚马逊店铺的卖家。

## 套用后会得到什么

1. **一个项目桌面**：进入后自动打开卖家后台、卖家精灵、1688、汇率页（企业微信装了就一起开，没装自动跳过）。
2. **一组上下文材料**：定价与毛利口径、Listing 文案规范、广告纪律、卖家政策入口。这些都是每天要用的判断依据，不用再翻笔记。
3. **一条工作流**：卖家后台巡查 → 今日必查清单 → 广告花费日报 → 汇总成 AI 上下文。
4. **一个可运行的脚本**：`广告花费日报`，接上广告 CSV 就能算出每个 SKU 的 ACOS 和超支名单。

## 参数说明

| 参数 | 作用 |
|---|---|
| 站点 | 决定项目名，方便同时开美国站、德国站多个项目 |
| 店铺名 | 项目名的一部分，多店铺时用来区分 |
| ACOS 红线 | 写进上下文与脚本默认值，改一次全项目生效 |

## 接入自己的广告报表

项目设置 → 功能/脚本 → 给「广告花费日报」加参数：

```
-DataFile "D:\报表\广告.csv" -AcosLine 20
```

CSV 需要三列：`SKU,花费,销售额`。导出方式：卖家后台 → 广告 → 广告报表 → 按 SKU 汇总。

## 建议的改造方向

- 把「今日必查清单」改成你自己的红线（比如库存周转天数）
- 加一个「竞品监控」网页节点，放在清理清单前面
- 你在项目里做的每一条修改，都可以再导出成一个自己的包（项目设置 → 导出为场景包），发给同事直接用
