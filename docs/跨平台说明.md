# 跨平台说明（Windows / macOS / Linux）

FDE 工作台从 7.26.0 起支持 **Windows**、**macOS（Intel 与 Apple M 系列）**、**Linux（X11）**。
核心思路：把所有"系统差异"集中到两个文件里，业务代码不再到处写 `powershell.exe`：

| 文件 | 作用 |
|---|---|
| `platform.js` | 能力矩阵：脚本用什么解释器、自启放哪、热键前缀、托盘图标…… |
| `wmp.js` | 窗口管理适配层：同一套命令协议（ENUM/HIDE/SHOW/MOVE/…），三个系统各自实现 |

---

## 各平台能力一览

| 能力 | Windows | macOS | Linux (X11) |
|---|---|---|---|
| 安装方式 | NSIS 安装包 / 绿色版 | dmg / zip | AppImage / deb |
| 窗口隔离（切桌面隐藏窗口） | ✅ 窗口级（Win32） | ⚠️ 应用级（隐藏整个 App） | ⚠️ 窗口级（需 xdotool） |
| 面板贴左缘（ AppBar 占位） | ✅ 系统级 | ⚠️ 置顶 + 贴边 | ⚠️ 置顶 + 贴边 |
| 按项目换壁纸 | ✅ | ❌ 不改壁纸 | ❌ 不改壁纸 |
| 开机自启 | 启动文件夹 | LaunchAgent | XDG autostart |
| 全局热键 | Ctrl+Alt+N | Cmd+Alt+N | Ctrl+Alt+N |
| 1688 搜索（GBK 编码） | ✅ iconv-lite / 代码页 | ✅ iconv-lite / 系统 iconv | ✅ 同左 |
| 知识库 / 卖货台 / 画布 / 应用功能 | ✅ | ✅ | ✅ |
| 管理员提权（UAC） | ✅ 自动提权 | 无此概念 | 无此概念 |

> macOS / Linux 的窗口隔离是"尽力而为"：授权或工具不满足时，软件照常运行，
> 只是"切换桌面"不会隐藏其它窗口（面板上会给出原因）。

## 安装后的一次性设置

### macOS（重要）
窗口隔离需要系统授权，否则看不到"切换桌面隐藏窗口"的效果：

1. 打开 **系统设置 → 隐私与安全性 → 辅助功能**；
2. 把 **FDE Manager** 加进去（第一次弹出授权框时点"允许"）；
3. 若还弹出"想要控制 System Events"，同样允许。

未授权时 FDE 会照常运行，只是窗口隔离自动关闭。

### Linux
- 建议在 **X11** 会话下使用；**Wayland** 下系统不允许跨应用隐藏窗口，FDE 会自动降级；
- 安装窗口工具：`sudo apt install xdotool wmctrl`（不装也能用，只是没有窗口隔离）。

## 源码运行 / 打包

```bash
npm install          # 安装依赖（含 electron 与 electron-builder）

npm run icons        # 生成三平台图标（build/icon.ico / .icns / .png）
npm start            # 源码运行

npm run dist:win     # Windows：NSIS 安装包 + 便携版
npm run dist:mac     # macOS：Intel(x64) + M系列(arm64) 的 dmg/zip（需在 Mac 上执行）
npm run dist:mac:universal   # macOS 通用二进制（一个包同时支持 Intel 和 M）
npm run dist:linux   # Linux：AppImage + deb
```

> mac 的 dmg 只能在 macOS 上打，Linux 的 AppImage 只能在 Linux 上打；
> 要在 Windows 上一次性出全部平台的包，用仓库里的
> `.github/workflows/build.yml`（推 tag 即自动在三个系统上打包，产物在 Actions 页面下载）。

产物在 `release/` 目录，文件名形如 `FDE-Manager-7.26.0-mac-arm64.dmg`。

> 国内网络下载 electron-builder 的打包工具经常超时，加一下镜像再跑：
>
> ```bash
> # Windows PowerShell
> $env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
> # bash
> export ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
> ```

## 打包要点（改配置前先读）

- `package.json → build.files`：只带运行必需文件，**不带** `fde-delivery.json`（渠道密钥）；
- `asarUnpack`：`winhelper.ps1` / `启动 FDE.vbs` 必须**解出 asar**（外部 PowerShell 读不了 asar 内的文件）；
- 图标：`npm run icons` 用 Electron 自己渲染（不依赖 ImageMagick），改完品牌再跑一次即可；
- 数据目录：仍然支持 `--data-dir=` / `FDE_DATA_DIR` / `portable.json`（绿色版），三个系统一致。

## 已知差异 / 边界

1. **项目自动打开**：macOS 上 `.exe` 无法运行——把启动项换成对应的 `.app` 或网址即可；
2. **脚本**：AI 生成的脚本在 Windows 上是 `.ps1`，在 mac/Linux 上是 `.sh`（`builder.js` 按 `platform.caps().scriptExt` 决定）；
3. **窗口管理命令失败不抛错**：`wmp.js` 每条命令失败只回空，主流程不会崩；
4. **管理员状态**：只在 Windows 显示"管理员/普通权限"，其它系统显示当前的隔离能力说明。
