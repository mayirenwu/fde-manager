# FDE Manager v7.26.3 — 三平台安装包

**公司里最值钱的软件，恰恰是 AI 摸不到的那批。** 工厂的 ERP / MES、金蝶、用友、政务系统、二十年的老 C/S 客户端——没有 API、不给接口、厂商早不更新，智能体想得到、碰不到。

FDE Manager 不截屏、不猜坐标——**直接调度你电脑上的原生窗口**：一台电脑 = N 张互不干扰的原生桌面，画布把窗口 / 网页 / 脚本 / 知识库 / AI / 生成节点连成一条线一键跑完。老软件一个字都不用改，只是从此有人替你把它打开、摆好、串进流程里。

## 校验（SHA256）

安装包未做代码签名，下载后请核对校验值：随包附 `checksums.txt`（与本页所有文件一一对应）。

```bash
# macOS / Linux
shasum -a 256 -c checksums.txt
# Windows PowerShell
Get-FileHash <文件名> -Algorithm SHA256
```

## 这一版能干什么

- **项目桌面**：按项目隔离真实窗口。切走时窗口真正隐藏（不是最小化），切回原位原样恢复 + 换壁纸，A 客户的报价永远不会出现在 B 客户的屏幕上
- **工作流画布**：十种节点（项目/窗口/网页/脚本/文件/笔记/AI/分组/生成），固定步骤走脚本，判断创作给模型，一条线一键跑完
- **本地知识库**：现有文件夹一键变可检索资料库，本地分词打分，只喂命中片段——断网也能用，token 省一个数量级
- **模型随便换**：任何 OpenAI 兼容接口都能接（DeepSeek / 豆包 / Kimi / 通义 / 自建 vLLM），换模型不换流程
- **一次搬走**：环境快照 + 绿色便携包，换电脑 = 搬一个文件
